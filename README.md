# herdr-boomerang

A Claude Code plugin for [Herdr](https://herdr.dev). Before Claude hits its usage limit, boomerang hands the work to Codex in a Herdr pane, and hands it back to Claude after the reset. Later it also sends cheap, read-only work to low-cost OpenCode models, and the results come back to Claude.

See `plans/v7-quiet-lighthouse.md` for the design.
